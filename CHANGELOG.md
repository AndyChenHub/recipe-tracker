# Changelog

All notable changes to Recipe Tracker iOS are documented in this file.

## [v0.1.0] - 2026-11-16

- Initial iOS Expo + Supabase cloud release
- Paprika-style Cookbook & Wake-Locked Cook Mode with checkable ingredients, interactive steps, pinned recipes, and inline tappable timers
- Dynamic serving scaler with kitchen fraction snapping, unit promotion, metric/US conversion, and live inline step scaling
- Smart Grocery List with canonical ingredient consolidation and supermarket aisle sorting
- Stateless temporary Pantry/Fridge scratchpad matcher ("Can I Make?") ranked by most matched items and fewest extra items needed
- Social media (TikTok, Instagram, YouTube Shorts) & Web `schema.org/Recipe` importer with native iOS Share Sheet support (`expo-share-intent`)
- Automated Semantic Versioning and EAS Cloud `.ipa` GitHub Release / TestFlight pipeline
